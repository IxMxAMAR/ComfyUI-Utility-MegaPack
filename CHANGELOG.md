## [Unreleased]

### Added
- Initial package scaffold.
- Operation registry pattern.
- Smoke / Echo node for registration verification.
- Theme system: 11 themes (Cyberpunk, Minimalist, Glassmorphic, Retro Terminal, Default, Holographic, Paper / Ink, Brutalist, Solarized Dark, Dracula, High-Contrast).
- Per-node theme picker widget, pack-wide default, ComfyUI-wide override.
- Motion gates honoring `prefers-reduced-motion`, manual reduce-motion setting, and a tunable heavy-theme node budget.
- 6 sidebar settings under `megapack.*`.
