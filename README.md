# ComfyUI-Utility-MegaPack

Comprehensive utility node pack for ComfyUI — ~165 operations across 7 nodes, 11 swappable visual themes.

**Status:** Pre-alpha. Foundation only.

## Install

Drop this directory into `ComfyUI/custom_nodes/` and restart ComfyUI.
